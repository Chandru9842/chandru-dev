# 📜 Changelog

All notable changes to the **Custom Portfolio CMS** project will be documented in this file. This project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [1.0.0] - 2026-07-18
### Added
*   **Split-Architecture Server Engine**: Complete full-stack Node.js Express server (`server.ts`) combined with React+Vite frontend.
*   **Holographic 3D Hero Scene**: Dynamic WebGL container rendering interactive planet earth models, custom particle galaxies, and high-tech scrolling laptop textures.
*   **Robust Security parameters**: JWT session parameters (cryptographically signed), BCrypt hashing, IP rate limiters, lockout thresholds, and audit trace records.
*   **Polished Content Managers**: Bento grid projects list, custom skills groupings, certificates timelines, career timelines, and automatic PDF resume builders.
*   **Adaptive Responsive Layouts**: Full mobile-responsive configurations including slide-out navigation drawers, touch targets, and automatic reduced-motion triggers.
*   **Zero-Dependency Analytics**: Complete visitor logging database, IP country telemetry, page path tracking, click trackers, and visual charts.
*   **Theme Overrides**: Integrated settings panel to modify primary palettes, copyright strings, and details globally with one click.
*   **Professional Documentation Suite**: Added `API_DOCUMENTATION.md`, `PROJECT_DOCUMENTATION.md`, `CONTRIBUTING.md`, and issue templates.
*   **Automated CI/CD**: Added GitHub Actions workflow in `.github/workflows/ci.yml` for automated linting, type checks, and production builds.
